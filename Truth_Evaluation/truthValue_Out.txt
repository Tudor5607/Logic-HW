Given that we only compute the truth value of each proposition under a single interpretation
and for any propositional formula with n>0 propositional variables we have 2^n interpretations,
we cannot say anything about the validity or nonsatisfiability of these formulas,
as for these properties we need to check all interpretations.

(a)P:True, Q:True

  ⇒

    Q

  ⇒

    True

∧
  True
  False

False

Because for this specific interpretation the formula evaluates to False, we can say the formula is invalid.

True

Because for this specific interpretation the formula evaluates to True, we can say the formula is satisfiable.
