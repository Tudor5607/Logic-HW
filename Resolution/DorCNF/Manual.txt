How to install:
Take the url of the folder containing this text file, and paste it into the website download-directory.github.io

How to use:
-Input:
The input file will contain on logical propositions on multiple rows (written in polish notation, propositions in polish notation can easily be obtained from the relaxed syntax parsing algorithm from this repo or can be transformed from standard propositions by hand). 

-Running the program:
The program can be run from inside an IDE like Visual Studio Code or directly from the terminal (note that the .py file must be run from inside the folder it is contained in, as the file input/output will not work otherwise).

-Output:
The output file will contain a step by step conversion of each propositional formula into one of its disjunction and conjunction normal forms.
Note: The output will be a text file whose contantes are intended to be pasted into a .tex document.
